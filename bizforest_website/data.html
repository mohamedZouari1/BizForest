Random Forest Output — 4 Land-Cover Classes
250 decision trees · 34 input features · Spatial cross-validation (4 folds)
Class 0 — Trees / Forest
Confirmed by ≥2 of 4 sources (DW, ESA WC, Hansen, spectral). Protected — not included in candidates.
Class 1 — Bare / Degraded
Candidate for reforestation. Receives MCE priority score. Main target of the analysis.
Class 2 — Built / Impervious
Excluded from candidates (NDBI + UI + 25m buffer). Cannot be planted.
Class 3 — Other
Water, seasonal crops, shrubland. Excluded via MNDWI + DW + NDWI + 60m water buffer.
Full Processing Pipeline
›
Step 1
GEE Ingestion
S2_SR_HARMONIZED filtered by date & cloud cover (<10%). SCL cloud mask applied. Median composite.
›
Step 2
Consensus Labels
Dynamic World mode + ESA WC + Hansen + spectral. Pixel labeled "tree" if ≥2 sources agree.
›
Step 3
RF Classification
700 samples/class × 4 classes. 34 features. Validated with 4-fold spatial cross-validation.
Step 4
MCE + Export
Priority score applied to Class 1 pixels. 4 levels classified. GeoJSON + GeoTIFF exported to Google Drive.
