About the Project

BizForest is a GeoAI platform developed during an internship to support urban reforestation planning in the Bizerte Governorate, Tunisia. It combines satellite data science, machine learning, and mobile technology into a single operational ecosystem.

🎯 Mission: Identify, prioritize, and help coordinate reforestation actions across Bizerte's 383,000 hectares using Sentinel-2 satellite imagery, a Random Forest classifier, and a multi-criteria priority model — all accessible from a browser or a smartphone.

Why Bizerte?

The Bizerte Governorate represents a critical environmental area in northern Tunisia. It combines dense urban zones (city of Bizerte, Zarzouna, Menzel Bourguiba), natural ecosystems (Lake Ichkeul, cork oak forests), and agricultural land under expanding urbanization pressure.

Hansen Global Forest Change data shows approximately 14,200 hectares of deforestation since 2000. The growing urban heat island effect — measurable via Landsat-9 Land Surface Temperature — makes targeted tree planting a public health and ecological priority.

The 3 Components

🛰️
GEE Analysis Script
bizerte_reforest_v4.js — Sentinel-2 composite, 10+ spectral indices, 3-source consensus labeling, Random Forest (250 trees, 34 features), MCE priority score, GeoJSON export.
🌐
Web Platform
bizforest_website/ — This multi-page website. Interactive GIS map (Leaflet.js), field survey form, planting logger, incident reporting, data statistics page.
📱
Mobile App
bizerte_reforest_agent/ — Flutter app "BizForest" with offline map (OSM), Firebase sync, GPS planting records, AI assistant (OpenRouter), 4 user role types.

Technology Stack

📡
Google Earth Engine
Cloud-based satellite processing. Used for all raster analysis, classification, and GeoJSON export.
🤖
Random Forest
GEE's built-in smileRandomForest classifier. 250 trees, 34 features, spatial cross-validation.
🗺️
Leaflet.js
Open-source JS mapping library used for the interactive web map and GeoJSON layer rendering.
📱
Flutter
Google's cross-platform mobile framework. Used for the BizForest field app (iOS + Android).
🔥
Firebase Firestore
Real-time cloud database for saving field surveys, planting records, and incidents from the mobile app.
💬
OpenRouter (LLM)
AI agent integrated into the mobile app to answer field agents' questions about species and protocols.

GeoJSON Output Files

  • bizerte_boundary.geojson — Governorate boundary (FAO GAUL 2015)
  • tree_cover.geojson — RF-classified tree cover polygons (≥ 0.2 ha)
  • very_high_priority.geojson — Reforestation zones with MCE score > 0.58 (Level 4)
  • high_priority.geojson — MCE score 0.45–0.58 (Level 3)
  • priority_zones.geojson — All priority zones (Levels 2, 3, 4 merged)
  • candidate_land.geojson — All plantable bare/degraded land
